# Katkıda Bulunma ve Soru Sorma Rehberi (`CONTRIBUTING.md`)

Bu proje açık kaynaklı bir akademik ve dijital beşerî bilimler çalışmasıdır. **Git veya yazılım bilmeden de** birkaç saniyede soru sorabilir, yeni ıstılah/sözlük karşılıkları veya prompt şablonları önerebilirsiniz.

## 1. Kod Bilmeden Katkı Sunma ve Soru Sorma (Önerilen)

Aşağıdaki hazır formlardan size uygun olanı seçip doldurmanız yeterlidir:

- ❓ **[Teknik Soru & Kurulum Desteği](https://github.com/shnfatih-hash/yazma-eser-paralel-tercume/issues/new?template=01-soru-ve-teknik-destek.yml)**
- 📖 **[Yeni Istılah / Sözlük (`glossary.md`) Katkısı](https://github.com/shnfatih-hash/yazma-eser-paralel-tercume/issues/new?template=02-terim-ve-sozluk-katkisi.yml)**
- 💡 **[Yeni Prompt, Yöntem veya Özellik Önerisi](https://github.com/shnfatih-hash/yazma-eser-paralel-tercume/issues/new?template=03-prompt-ve-yontem-onerisi.yml)**
- 🐛 **[Hata / Betik / Tahkik Sorunu Bildirimi](https://github.com/shnfatih-hash/yazma-eser-paralel-tercume/issues/new?template=04-hata-bildirimi.yml)**
- 💬 **[Hugging Face Topluluk Tartışmaları](https://huggingface.co/spaces/sahanfatih/yazma-eser-paralel-tercume/discussions)**

## 2. Geliştiriciler İçin Pull Request (PR) ile Katkı

1. Depoyu fork edin ve yeni bir dal (`branch`) açın.
2. Değişikliğinizi yapın (`examples/`, `references/`, `scripts/` vb.) ve Python betiklerini test edin.
3. Kısa bir açıklama ile Pull Request gönderin.
